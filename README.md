# Eldenquizzzz

Elden Ring quiz with embedded images.

Play at **https://fowlong.github.io/Eldenquizzzz/**.

`index.html` is the complete, self-contained quiz. Open it in a browser to play locally.

GitHub Pages publishes the root of the `main` branch. Update `index.html` and push to `main` to update the website. The `.nojekyll` file lets GitHub serve the HTML directly.
